# 第3回：Read — 一覧・詳細・検索

目標：URLの条件からSELECT、EJS表示まで追う。

## 基礎と実コード

GETはリソースを取得するHTTPメソッド。`/questions?q=SQL` の `q` はURLの検索条件で `req.query.q` に入る。`/questions/12` の12はルートの `:id` に対応し `req.params.id` に入る。どちらもフォーム本文の `req.body` と区別する。

[app.js](../../app.js) 94〜113行の `GET /questions` を追う。

1. 検索語・カテゴリ・状態・並べ替え・ページを受け取る。
2. `values` に値を入れ、`where` に検索条件を作る。
3. `ILIKE` で大文字小文字を区別せず部分一致検索する。入力の `%`・`_` などは文字として検索するためエスケープする。
4. 並べ替えは固定のSQL候補から選ぶ。
5. 最大21件取得し、20件を表示、残る1件で次ページの有無を判定する。
6. `res.render('index', ...)` から [views/index.ejs](../../views/index.ejs) へ渡す。

詳細は `GET /questions/:id`（166〜173行）。`getQuestion`（128〜131行）でIDの形式と存在を調べ、なければ404。`getAnswers` は `WHERE a.question_id=$1` でその質問の回答だけを取得する。
