# 学習終了・持ち帰り記録

以下をコピーして埋める。テンプレート自体は回答履歴として扱わない。

```text
記録ID：YYYY-MM-DD-HHMM-識別子（JST、同名を避ける）
日時：
担当：ChatGPT／Codex（モデル不明なら不明）
開始時ブランチ：study-notes
開始時コミット：取得不可なら取得不可
開始時進捗リビジョン：learning-0001等
使用した資料：GitHub最新／添付スナップショット
学習回・問題：

本人の回答要約：
AIが補足した内容：
補足後の本人の再説明：未実施なら未実施
確認コード：ファイル・関数／ルート（確認した版）
理解確認結果：説明可能／再確認が必要／未確認

本人が操作したこと：未実施なら未実施
根拠：本人の報告／画面確認など、確認方法と範囲
AIのみが操作・検証したこと：本人操作と分ける
未解決の疑問：
次回の開始地点：一問または一操作を具体的に

保存状態：Git未保存／Git保存済み
保存先・コミット：保存できた場合のみ記入
```

取り込む側は開始時リビジョンと最新記録を照合する。古い要約で最新進捗全体を置き換えない。別の記録と矛盾した理解状態は本人へ確認し、確定までは未確認として両方の経緯を残す。
