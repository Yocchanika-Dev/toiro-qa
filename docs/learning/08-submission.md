# 第8回：総復習・動画・提出

目標：GitHubで実コードを示し、自分の言葉でCreate・Update・Deleteを説明して提出する。

## 課題条件の要点

出典：作業フォルダ直下 REQUIREMENTS.md（配布資料・提出フォームの転記）。2026-11-14照合。原本はリポジトリ外。要件変更時は原本を優先する。

- 基本50点＋動画20点＋発展30点。得点を保証するものではない。
- 動画は約5分、本人の声で、ブラウザのGitHubに実コードを映す。
- Createはフォーム値の受け取りとDB保存、Updateは対象特定とDB更新、Deleteは対象特定・DB削除・関連回答の扱いを説明する。
- 提出動画は通常のMac環境で再生可能な形式、1ファイル・1GB以内。
- GitHub URLと公開アプリURLの両方を外部から閲覧できること。
- フォームで発展7項目を申告する。チェックしない項目は採点対象外。
- AIを使った範囲と本人が実際に確認・修正した内容を事実どおり記す。
- 締切12月10日17:00 JST。年の明記なし、作業年度の文脈では2026年。

## コードを指して答える

1. Create：フォームのnameからreq.body、validate、INSERT、RETURNING idまで。
2. Update：req.params.id、getQuestion、所有者確認、SET、WHERE、値の配列まで。
3. Delete：確認GETと実行POST、所有者条件、DELETE、ON DELETE CASCADEまで。

対応コードは第2・4・5回へ。言葉が詰まった箇所を復習し、暗記した文章だけで進めない。

## 収録準備と本人操作

[RECORDING_GUIDE.md](../../RECORDING_GUIDE.md) は旧コミットの行番号を参照しているため、現コードと照合してから使う。本教材作成では台本の更新・本人の確認完了扱いはしていない。

構成の目安：概要20秒、Create95秒、Update80秒、Delete85秒、まとめ20秒。
本人の言葉へ直して短く試し録りし、コードの可読性・声・所要時間を確認する。認証は録画前に済ませ、実名・メール・パスワード・環境変数・管理画面を映さない。

動画全編を再生し、容量・形式を確認する。本人情報はフォームだけに入力する。両URL・動画・発展7項目・AI利用申告を揃え、送信完了まで確認する。
収録や送信は未実施のままチェックしない。完了した節目を [進捗](PROGRESS.md) へ記録する。
